# Ordinary Form Decoder

Обычная форма хранится в `Form.bin`, а RLM нужен её читаемый состав: элементы, реквизиты и связи с обработчиками. Этот скрипт извлекает их в `Form.xml`, а модуль формы — в `Form/Module.bsl`. Исходный файл он не меняет; собирать форму обратно не умеет.

Можно разобрать одну форму или пройти весь каталог, включая выгрузки внешних обработок и отчётов. Для запуска достаточно Python 3.10+ и двух файлов рядом: `ordinary_form_rlm.py` и `ordinary-form-events.json`. Подробности — в [справке](README.html).

Разборщик сохраняет найденное имя обработчика, даже если не смог определить тип события: в XML такое событие помечается как неизвестное. Действия кнопок `CommandBar`, в том числе во вложенных группах, связываются с обработчиками по UUID. Встроенные команды платформы за BSL-обработчики не выдаются.

```powershell
python .\ordinary_form_rlm.py "C:\Work\export\Form.bin" --output "C:\Work\output"
python .\ordinary_form_rlm.py "C:\Work\export" --recursive --output "C:\Work\output"
python -m unittest discover -s tests
```

Словарь событий можно дополнить под свои формы. Он помогает распознавать имена, но не назначает числовые ID сам по себе: для этого разборщик анализирует формы проекта.

Реализация разработана отдельно от `onec-ordinary-forms`. Этот проект помогал изучать формат и сравнивать результаты, но его исходный код здесь не использован. Благодарим автора Maxon за опубликованную работу.
