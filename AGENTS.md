# Правила разработки

- Разборщик однонаправленный: `Form.bin` → `Form.xml` и `Form/Module.bsl`. Не добавляйте обратную сборку.
- `ordinary_form_rlm.py` — единственный исходник алгоритма; `ordinary-form-events.json` — пользовательский редактируемый словарь.
- Не переносите исходный код `onec-ordinary-forms`. Этот проект можно использовать только для исследования формата и сравнения результатов.
- При изменении CLI или поведения обновляйте `README.html`, `README.md` и тесты.
- Перед фиксацией запускайте `python -m unittest discover -s tests` и `git diff --check`.
